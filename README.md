# Crestie Lineage v5
크레스티드 게코의 개체·성장·유전·교배·가계도와 사진을 관리합니다.

## 노트북과 휴대폰에서 사용
- 두 기기에서 https://cre-flame.vercel.app 을 엽니다.
- 조회는 별도 API 키 없이 가능합니다.
- 작성할 기기는 상단 저장 상태를 눌러 **기록 저장용 비밀번호**를 한 번 입력합니다.
- 저장 버튼을 누르면 먼저 이 기기에 보관하고 자동으로 클라우드에 저장합니다.
- **✓ 클라우드 저장됨** 표시가 뜨면 다른 기기에서도 조회할 수 있습니다.
- 사이트를 다시 열거나 화면으로 돌아오면 최신 내용을 확인하며, 열린 화면에서도 15초마다 동기화합니다.
- 오프라인 변경은 브라우저에 남고 재접속 시 다시 저장합니다. 저장 대기 중에는 브라우저 데이터를 지우지 마세요.

서로 다른 기록이나 필드의 변경은 자동으로 합칩니다. 같은 항목이 충돌하면 상단 상태 버튼에서 양쪽 기록을 백업하고 사용할 내용을 선택합니다. 삭제도 기기 사이에 반영됩니다.

## 저장 구조
기존 Vercel Blob 연결을 그대로 사용합니다. 사용자가 GitHub 토큰이나 Blob API 키를 발급할 필요는 없습니다.
- 데이터: `crestie/current.json`
- 사진: `crestie/photos/`
- 기존 v4 데이터: `crestie/data/` 전체 페이지에서 최신 기록을 가져옵니다. 이전 파일은 삭제하지 않습니다.
- 서버는 최신 데이터의 ETag를 기준으로 조건부 저장하여 동시에 열린 기기가 기록을 덮어쓰지 않게 합니다.
- 브라우저의 기존 `crestie-lineage-v1` 저장 키를 유지합니다. 마지막 동기화 기준과 미전송 변경을 함께 보존합니다.
- 사진은 최대 1400px로 압축하여 업로드합니다.

## 운영 설정
현재 프로젝트에 연결된 `BLOB_STORE_ID`와 Vercel 인증을 사용합니다. 기존 `BLOB_READ_WRITE_TOKEN` 연결도 SDK에서 지원합니다.
`CRESTIE_SYNC_KEY`는 작성 보호용 비밀번호입니다. 비밀번호를 바꾸면 Production에 재배포한 뒤 작성 기기에 새 비밀번호를 입력합니다. 비밀번호는 코드나 GitHub에 넣지 않습니다.
기본 저장소 접근 모드는 기존 구성과 같은 public입니다. 기록 조회 API와 사진 주소는 공개되어 있으며 작성만 비밀번호로 보호합니다. 비공개 서비스로 바꾸려면 조회 인증과 사진 제공 방식도 함께 변경해야 합니다.

## 검증
`pnpm install --frozen-lockfile` 후 `pnpm test`.
테스트는 실제 사육 기록에 쓰지 않는 격리된 저장소 모형에서 동시 저장, 오프라인 복구, 삭제 전파, 기존 데이터 이전 및 비밀번호 보호를 확인합니다.
