# Crestie Lineage v6 — GitHub 자동 저장

크레스티드 게코의 개체 정보·성장·교배·가계도와 사진을 관리합니다.

## 사용
- 노트북과 휴대폰에서 https://cre-flame.vercel.app 을 엽니다.
- 작성할 기기에서 상단 저장 상태를 눌러 기록 저장용 비밀번호를 한 번 입력합니다. API 키를 발급하거나 코드에 넣을 필요가 없습니다.
- 저장 버튼을 누르면 이 기기에 먼저 보관한 뒤 GitHub에 자동 저장합니다.
- **✓ GitHub 저장됨** 표시를 확인하면 다른 기기에서도 기록을 볼 수 있습니다.
- 다른 기기의 변경은 사이트를 열거나 화면에 돌아왔을 때, 또는 15초 주기로 확인합니다.
- 오프라인 기록은 브라우저에 유지하고 재접속 시 재시도합니다. 저장 대기 중에는 브라우저 데이터를 지우지 마세요.
- 같은 항목을 두 기기에서 다르게 수정하면 상단에서 충돌을 확인하고 사용할 내용을 선택합니다. 다른 항목의 변경은 자동으로 합칩니다.

## 저장 위치
- 정보: steo410/cre 저장소의 crestie-data 브랜치, data/cresties.json
- 사진: 같은 브랜치의 data/photos/
- 프로그램: main 브랜치
- 저장 연결 시험 파일: data/sync-check.json (실제 사육 정보 없음)

저장소가 공개되어 있어 기록과 사진도 공개됩니다. 작성만 비밀번호로 보호합니다. 비밀번호와 GitHub 연결 토큰은 GitHub에 저장하지 않습니다.

기존 브라우저 저장 키와 기록을 유지합니다. 저장 실패로 브라우저에 남은 기록은 새 서버 연결 시 자동 업로드합니다. 기존 Blob 저장소 파일을 삭제하지 않습니다. 이번 전환 시 Blob 데이터가 비어 있음을 확인했습니다.

## 서버
Vercel의 기존 CRESTIE_GITHUB_TOKEN과 CRESTIE_SYNC_KEY 설정을 사용합니다. 데이터 API는 GitHub 파일 SHA를 기준으로 조건부 저장하여 오래된 기기의 덮어쓰기를 방지합니다. 사진은 새 파일로 저장하여 기존 사진을 덮어쓰지 않습니다.
한글 비밀번호는 브라우저에서 SHA-256으로 변환하여 HTTP 헤더로 전달합니다. 이 값 역시 인증 정보이므로 로그에 출력하지 않습니다.
