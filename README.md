# Crestie Lineage

크레스티드 게코의 개체 정보, 성장 기록, 교배 관계, 가계도를 브라우저에서 관리하는 정적 웹앱입니다.

## 주요 기능
- 개체: 이름, 모프/품종, 성별, 부화일, 입양일, 브리더, 메모, 부모 1/2
- 성장: 날짜별 체중(g), 전장(cm), 상태, 메모
- 성장 그래프: 체중과 전장을 자동 SVG 그래프로 표시
- 자동 가계도: 부모 정보를 기준으로 세대를 계산하고 자동 배치
- 교배 관계: 형제·자매 / 부모·자식 / 조상·후손도 등록 가능
- 순환 방지: 한 개체가 자기 자신의 조상이 되는 잘못된 부모 연결만 차단
- 백업/복원: JSON 파일 다운로드 및 불러오기
- 저장 방식: 브라우저 LocalStorage 자동 저장

## 실행 방법
별도 설치가 필요 없습니다.

1. 폴더에서 `index.html`을 더블 클릭해도 대부분 기능이 동작합니다.
2. 더 안정적으로 확인하려면 VS Code의 Live Server 확장 또는 간단한 로컬 서버를 사용하세요.

예시:
```bash
python -m http.server 8000
```
그 뒤 브라우저에서 `http://localhost:8000` 접속.

## GitHub + Vercel 배포
1. GitHub에서 새 저장소를 생성합니다.
2. `index.html`, `style.css`, `app.js`를 저장소 루트에 업로드합니다.
3. Vercel에서 **Add New → Project**를 누르고 해당 GitHub 저장소를 선택합니다.
4. Framework Preset은 `Other`, Build Command는 비워두고, Output Directory도 비워둔 상태로 배포합니다.

## 데이터에 대한 주의
현재 버전은 서버/계정 없이 한 브라우저 안에 저장합니다. 브라우저 데이터 삭제나 PC 변경 전에 `백업 · 복원` 메뉴에서 JSON 백업 파일을 저장하세요.

나중에 여러 기기 동기화가 필요하면 Supabase/Firebase 로그인과 DB를 붙일 수 있습니다.
