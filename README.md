# Crestie Lineage v2

크레스티드 게코의 **개체 정보, 성장 기록, 유전 정보, 교배 예상, 교배 관계, 자동 가계도**를 브라우저에서 관리하는 정적 웹앱입니다.

## 주요 기능
- 개체: 이름, 모프/품종, 성별, 부화일, 입양일, 브리더, 메모, 부모 1/2
- 성장: 날짜별 체중(g), 전장(cm), 상태, 메모
- 성장 그래프: 체중 기록을 자동 그래프로 표시
- 자동 가계도: 부모 정보를 기준으로 세대를 계산하고 자동 배치
- 교배 관계: 형제·자매 / 부모·자식 / 조상·후손 관계도 기록 가능
- 순환 방지: 한 개체가 자기 자신의 조상이 되는 잘못된 부모 연결만 차단
- 유전 정보: 릴리화이트, 아잔틱, 카푸치노, 솔리드백 기록
- 아잔틱: 비주얼 / 100% 헷 / 66% 헷 / 50% 헷 / 유전자 없음 구분
- 부모 유전 정보에서 자식의 가능한 유전 상태 자동 추론
- 통용 표기: 릴리아잔틱/릴잔틱, 솔리드릴리, 프라푸치노 등의 별칭 표시
- 분양 표기 분석: `웨코x노멀 (북이/설기)`처럼 괄호 안 부모 이름이 등록되어 있으면 자동 연결 가능
- 교배 예상: 사용자가 선택한 두 개체만 계산
- 성별 미확인 개체는 수컷/암컷 어느 쪽과도 교배 후보로 사용 가능
- 릴리×릴리도 계산을 막지 않고 슈퍼 릴리 가능성을 포함해 표시
- 솔리드백은 단일 멘델 확률로 임의 계산하지 않고 표현 가능성으로 표시
- 백업/복원: JSON 파일 다운로드 및 불러오기
- 저장 방식: 브라우저 LocalStorage 자동 저장

## 실행 방법
별도 설치가 필요 없습니다. 저장소 루트의 `index.html`을 열거나 Vercel에 정적 사이트로 배포하면 됩니다.

## 데이터 저장 주의
현재 데이터는 서버 계정이 아니라 **현재 브라우저의 LocalStorage**에 저장됩니다. 브라우저 데이터를 삭제하거나 다른 PC로 옮기기 전에는 `백업 · 복원` 메뉴에서 JSON 백업 파일을 저장하세요.

## 기존 v1 데이터
v1에서 사용하던 LocalStorage 저장 키를 유지하므로 기존 개체·성장·가계도 데이터를 계속 읽습니다. 새 유전 정보가 없는 기존 개체는 유전 상태가 `미확인`으로 시작합니다.
